# まなびポケット

小学生から高校生までを対象にした、学年別の問題と学習記録を試せる学習アプリのMVPです。

## 起動方法

`index.html` をブラウザで開くと使えます。ビルドや依存パッケージは不要です。

## できること

- 小学1年生から高校3年生までの学年を選択
- 学年と教科を選び、複数の単元と問題数を設定して問題に挑戦
- 小学6年生の算数は、学習指導要領の領域をもとに整理した8単元から、計算・考え方・文章題を組み合わせて出題
- 小学6年生の算数で標準問題と応用・適性検査対策の問題を切り替え
- サイドメニューに、家庭教師まなびやの「できた！」を一つずつ積み上げる考え方を取り入れた日替わりメッセージを表示
- デスクトップのサイドメニュー、スマートフォンのホーム画面、問題画面から、詳しい解説や学習相談を希望する人向けに家庭教師まなびやの案内を表示
- 正誤と解説の確認、挑戦回数・正解数・学習日数の記録
- 問題に回答するたびに学習記録を保存し、「学習のきろく」画面で過去50回分の教科・単元・学年・回答数・正解数を確認
- スマートフォンとデスクトップに対応した画面

小学6年生の算数は標準問題と応用問題を切り替えられます。標準問題は、学習指導要領の領域をもとに整理した8単元から計算・考え方・文章題を出題し、学習ごとに数値を変えます。小数の答えは小数第2位を四捨五入して小数第1位まで求める形式です。各単元の直近200問と同じ問題を避け、出題履歴はこのブラウザに保存します。割合・百分率では、もとにする量や比べられる量、値引き・値上がりなどを練習できます。学習指導要領解説の「数と計算」「図形」「変化と関係」「データの活用」を軸にしています。速さ・単位量あたりは関連する既習内容の活用問題です。その他の学年・教科はサンプル問題です。

小学6年生の算数の「応用・適性検査対策」には、分数、割合、比、速さ、図形、縮尺、データ、文字式、場合の数・条件整理の各単元に50問ずつ、合計450問を出題します。複数の問題形式を使い、数値や条件を学習ごとにランダムに変えます。小数の答えは小数第2位を四捨五入して小数第1位まで求める形式です。直近200問と同じ問題文は避けます。公開問題の転載ではなく、指定ページの対象領域や「場面を読み取り式を立てる」という学習方針を参考に独自に作成しています（[文章問題Ⅰ](https://happylilac.net/mu1612291631.html)、[文章問題Ⅱ](https://happylilac.net/mu1701251717.html)、[文章問題まとめ](https://happylilac.net/s19_bun_6-ms202601211012.html)）。記述式や学校別の適性検査対策は今後の拡充対象です。

単元構成は、文部科学省の小学校学習指導要領解説 算数編の各学年の内容をもとに、このアプリ向けに整理しています。学習指導要領は教科書の章立てを定めるものではないため、教科書会社や学校によって単元名・順序は異なります。

- [文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)
- [文部科学省「学習指導要領等（平成29・30・31年改訂）」](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)

学習記録はブラウザの `localStorage` に保存され、サーバーには送信されません。ブラウザのデータを消去すると記録も消えます。ほかの学年・教科の問題は、今後の拡充対象です。

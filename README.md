# まなびポケット

小学生から高校生までを対象にした、学年別の問題と学習記録を試せる学習アプリのMVPです。

## 起動方法

`index.html` をブラウザで開くと使えます。ビルドや依存パッケージは不要です。

## できること

- 小学1年生から高校3年生までの学年を選択
- 学年に合わせた教科から3問のクイズに挑戦
- 正誤と解説の確認、挑戦回数・正解数・学習日数の記録
- 問題に回答するたびに学習記録を保存し、「学習のきろく」画面で過去50回分の教科・学年・回答数・正解数を確認
- スマートフォンとデスクトップに対応した画面

学習記録はブラウザの `localStorage` に保存され、サーバーには送信されません。ブラウザのデータを消去すると記録も消えます。問題は動作確認用のサンプルで、カリキュラム全体を網羅するものではありません。

# まなびポケット

小学生から高校生までを対象にした、学年別の問題と学習記録を試せる学習アプリのMVPです。

## 起動方法

`index.html` をブラウザで開くと使えます。ビルドや依存パッケージは不要です。

## できること

- 小学1年生から高校3年生までの学年を選択
- 学年と教科を選び、複数の単元と問題数を設定して問題に挑戦
- 小学6年生の算数は、学習指導要領の内容をもとに整理した6単元から各30問を用意し、選んだ単元と問題数に合わせてランダムに出題
- 正誤と解説の確認、挑戦回数・正解数・学習日数の記録
- 問題に回答するたびに学習記録を保存し、「学習のきろく」画面で過去50回分の教科・単元・学年・回答数・正解数を確認
- スマートフォンとデスクトップに対応した画面

小学6年生の算数は「分数のかけ算・わり算」「比と比例・反比例」「速さ・単位量あたりの大きさ」「円の面積・体積」「拡大図・縮図と対称な図形」「データの活用」の6単元です。問題は計算値やデータを変えて生成し、単元ごとに30問を用意しています。その他の学年・教科はサンプル問題です。

単元構成は、文部科学省の小学校学習指導要領解説 算数編の各学年の内容をもとに、このアプリ向けに整理しています。学習指導要領は教科書の章立てを定めるものではないため、教科書会社や学校によって単元名・順序は異なります。

- [文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)
- [文部科学省「学習指導要領等（平成29・30・31年改訂）」](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)

学習記録はブラウザの `localStorage` に保存され、サーバーには送信されません。ブラウザのデータを消去すると記録も消えます。ほかの学年・教科の問題は、今後の拡充対象です。
